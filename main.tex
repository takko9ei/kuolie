  % 想用自定义颜色就改用下面这行(六位十六进制,不要写 #):

  %-- 中文字体 --------------------------------------------------------------
  % auto      自动探测,优先 Noto Sans CJK SC,最后退回 TeX Live 自带的 Fandol

  % sourcehan Source Han Sans SC (思源黑体,与 Noto 同源)

  %-- 版式 ------------------------------------------------------------------

  titlespread = 0.06,      % 小标题字距,0 = 不加
